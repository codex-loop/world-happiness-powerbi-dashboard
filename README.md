# World Happiness Dashboard (Power BI)

This project analyzes the World Happiness Report 2019 dataset using Power BI.

## Dashboard Features
- Average happiness score
- Top 10 happiest countries
- GDP vs happiness relationship
- Factors affecting happiness
- Interactive filters

## Tools Used
- Power BI
- Data Visualization
- Kaggle Dataset

## Dataset
World Happiness Report 2019 dataset from Kaggle.
